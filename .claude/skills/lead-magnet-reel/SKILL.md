# Lead Magnet + Reel Script

Two phases. Never skip phase 1 gate.

## Phase 1: Research, ideas, script

### Step 0: Ask first
Ask the user exactly one question, then stop and wait:
1. What is your niche? Who do you help, and with what?

### Step 1: Audience problems
Use WebSearch (load with ToolSearch if deferred). Cover:
- Google Trends: rising and breakout searches, last 12 months
- Google "People also ask" and autocomplete
- Reddit, Quora, forums: complaints and help requests
- TikTok, Instagram, YouTube: popular topics in the niche

List the 10 most common, urgent problems, ranked by demand. For each:
- Problem in the audience's own words
- Why it hurts now
- Demand signal (trending, FAQ, engagement)

### Step 2: 5 lead magnet ideas
Formats: guide, ebook, checklist, template, prompt pack, cheat sheet, mini-course. For each:
- Catchy title
- Format
- Problem solved
- Why irresistible (quick win, specific, easy to consume)
- What's inside (3-5 bullets)

Recommend the single best one in two sentences.

### Step 3: Video script (30-45 s, recommended magnet)
Structure, in order:
1. **HOOK** (first 3 s): bold result, or call out the painful problem directly. Pattern: "[Method] helped me get [result]..." or "If you're struggling with [problem], watch this."
2. **PROOF**: one line with specific numbers or a result.
3. **SOLUTION**: 2-3 steps. Each one short sentence starting "First...", "Then...", "And...".
4. **BONUS**: "And here's the best part..." plus one extra value.
5. **CTA**: "Want this for free? Just comment [KEYWORD] and follow me so the message gets delivered."

Script rules:
- Short spoken sentences, like talking to a friend
- Specific numbers wherever possible
- No fluff, no long intro
- Every line makes viewer want the next

Also deliver:
- 3 alternative hooks for A/B test
- On-screen text for first 3 seconds
- Post caption with CTA keyword repeated
- Automated DM the commenter receives

End with exactly: "Do you want me to create this lead magnet for you now?"

## Phase 2: Build the lead magnet
Runs only after the user picks 1-5 (or confirms the recommended one).

Requirements:
- Quick win the reader uses within 10 minutes
- Clear structure: headings, short paragraphs, bullets
- Practical: examples, templates, step-by-step actions. No theory filler
- End with soft CTA to paid offer: `[YOUR OFFER]` or free call (ask user for the real offer if not given; keep placeholder otherwise)
- Format ready to export as PDF (single column, numbered sections, no external assets). Use the pdf skill to export if user asks for a file.

## Language
Reply in the user's language. Keep keyword and offer placeholders exact.
