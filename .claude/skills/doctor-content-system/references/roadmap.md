كل دكتور جديد بيعدّي بالترتيب ده. الوضع: `client` (هيشتغل معاك) أو `case_study`.

### 2. سحب الحسابات + لقطة البداية
- **أداة:**
  - إنستجرام (بروفايل + 60 بوست + المرحلة + الناجح/الفاشل + البايو): ✅
  - فيسبوك (صفحة + 30 بوست + نفس دقة إنستجرام): ✅ (`fetch_facebook.py` + `analyze_facebook.py`، عن طريق Apify ~0.17$. السحب المباشر المجاني **اتجرب وفشل**، فيسبوك بيحوّل لصفحة لوجين حتى بدون حماية شبكة)
  - لقطة البداية (`baseline.py`) لمقارنة يوم 30/60: ✅
  - أنجح 2 + أضعف 1 ريل: فيديو مجاني (CDN) + سكريبت مجاني (faster-whisper محلي، ~25 ثانية للريل): ✅
- **منفّذة مع:** د. مصطفى ✅ (إنستجرام + فيسبوك + فيديو وسكريبت)

### 3. مراجعة يوسف للفيديوهات (إجباري قبل أي تقرير)
- **أداة:** ✅ `forms/video_review.md` — تقييم من 10 لكل بند (هوك لفظي/بصري، أسلوب الكلام، الحضور، الإضاءة، الصوت، المونتاج، الكابشن، التايتل، الـCTA) + معايير يوسف الثابتة
- **منفّذة مع:** د. مصطفى ✅ (7 بنود، كلها بأرقام وحلول)

### 4. مسح التخصص: 5 دكاترة ناجحين
- **أداة:** ✅ بحث جوجل عن طريق Apify (`research_fetch.py`) + تحقق من الحسابات + آخر 20 ريل + تحليل الأنماط (`analyze_competitors.py`)
- **منفّذة مع:** د. مصطفى ✅ (5 دكاترة حقن مجهري ونسا وتوليد، 92 ريل)

### 5. التقرير
- **أداة:** ✅ `build_audit.py` → PDF إنفوجرافيك (طبي هادي) + MD للدكتور + MD داخلي ليك
  - قسم إنستجرام: أرقام، أنجح فيديو، 3 مشاكل وحلولها، ملاحظات الفيديو /10، أنماط التخصص
  - قسم فيسبوك: نفس بنية إنستجرام بالظبط (ناجح/فاشل بمؤشر خاص بكل نوع بوست، بيانات الصفحة)
- **منفّذة مع:** د. مصطفى ✅ (7 صفحات، آخر نسخة بعد تصحيح الأرقام المقلوبة RTL)

### 6. أسئلة المكالمة (بعد ما الدكتور ياخد التحليل)
- **أداة:** ✅ قالب 27 سؤال / 7 أقسام (التخصص، المريضة النموذجية، الشخصية، التصوير، الهدف، طريقة الشغل)

## ⚙️ قواعد ثابتة (كل خطوة لازم تحترمها)

- كل تعديل نتفق عليه في الكلام يتسجل في السكيل فورًا، وهذا الملف يتحدث معاه.
- موافقة يوسف قبل أي خطوة جديدة وقبل أي خطوة بفلوس.
- مفيش تقرير يتبني أو يتبعت قبل ما `video_review.md` يوصل.
- كل نتيجة أو ادعاء في التقرير جنبه لينكه.
- بيانات الدكاترة في `outputs/doctors/` متزامنة على git (قرار يوسف 2026-11-05) عشان تبقى على الجهاز والأكونت. الفيديوهات الكبيرة (>20MB) متترفعش.
- لو أي Apify run اتوقف، يتوقف على Apify نفسه كمان (abort) مش يتسابش يصرف.
- الطريق المجاني أولًا (فيديو CDN + سكريبت محلي)، Apify احتياطي لما المجاني يفشل أو مش متاح.
- `preflight.py` قبل أي خطوة بحث، عشان نعرف أي دومين متاح قبل ما نحاول.
